04

Production automation · Correctness critical send path

Deterministic Email Campaign Engine

A client wanted AI writing customer facing emails in a live send path. The brief demanded provable correctness, so I designed a deterministic engine and kept the model out of the path where being wrong is not recoverable. Only the client's own words are ever sent.

n8nMicrosoft GraphAirtableJavaScriptOAuth 2.0
  • An 89 node legacy workflow re-architected into a four workflow system: campaign portal, follow up engine, reply and bounce handling, live monitoring
  • Code enforced guardrails: hard follow up cap, per run circuit breaker, per recipient cooldown, duplicate stage guard
  • An assertion that throws before sending if the greeting does not match the recipient
  • Bounce and out of office detection so only genuine delivery failures stop a sequence
ImpactA 180 message concurrency regression across four simultaneous campaigns passed with zero wrong name errors and no duplicates before go live.

Production support · Observability · Incident response

Production Resilience and Monitoring

Inherited a live automation estate that had suffered an eighteen hour silent outage, with five of seven workflows running with no error alerting at all. Rebuilt the operational layer around it.

n8nMicrosoft GraphSlackPythonGrafanaLoki
  • Error alerting and heartbeat stuck detection built from scratch, running at zero incremental cost
  • Around fifty integration nodes retry hardened in a single audit pass
  • Fragile polling triggers replaced with scheduled fetch and duplicate detection, structurally removing the stall class
  • Lost records recovered by API driven execution retries
ImpactRecurring stalls eliminated. Monitoring became a standard requirement on every deployment that followed.
